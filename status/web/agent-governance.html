自动失效规则

下列任一变化都会让旧证据立即失效，不再沿用旧绿色。

实现路径或依赖变化

subject_commit 变了，绑定在旧提交上的结论一律作废。

部署摘要不一致

仓内、部署清单与生产 HTTP 取到的 digest 四者必须一致。

TTL 到期或采集失败

超出证据 TTL 或采集报错，状态回落 UNKNOWN / STALE。

基础设施事实边界

哪一层是权威、哪一层只是投影，必须机器可分。

事实流向

运行与采集 → 结构化事实 → 对象与冷备 → 异地恢复 → 只读展示。

status 只做最后一段的只读展示；长期事实一律回写 Private-Database，控制面不得成为第二事实源。
